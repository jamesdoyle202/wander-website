# Push changes to GitHub

**1. Open Terminal**
- Spotlight (Cmd + Space) → type **Terminal** → Enter

**2. Go to project**
```bash
cd /Users/jamesdoyle/wander-website
```

**3. Stage & commit**
```bash
git add .
git commit -m "Describe your changes here"
```

**4. Push**
```bash
git push
```

---
*Terminal → cd into project → git add . → git commit -m "message" → git push*
